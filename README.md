# MathSolver Automation Testing using Selenium

An automated math problem solver and testing tool built using Python and Selenium WebDriver.
The project demonstrates how browser automation can interact with online math-solving platforms, submit mathematical expressions, and extract computed results automatically.

This project highlights practical skills in automation testing, web interaction, and Python scripting.

🚀 Project Overview

MathSolver automates the process of solving mathematical problems by:

1️⃣ Launching a web browser using Selenium WebDriver
2️⃣ Navigating to an online math solver website
3️⃣ Automatically entering mathematical expressions
4️⃣ Retrieving the calculated result
5️⃣ Validating and displaying the output

This approach demonstrates real-world browser automation and automated testing workflows.

✨ Features

✅ Automated browser interaction using Selenium
✅ Automatic submission of mathematical expressions

⚙️ Installation
1️⃣ Clone the Repository
git clone https://github.com/saibhargavi-rapolu/mathsolver.git

cd mathsolver

2️⃣ Install Dependencies
pip install -r requirements.txt

If Selenium is not installed:

pip install selenium
▶️ Running the Project

Run the main script:

python calculator_test.py

The automation will:

Launch a browser

Enter math expressions

Retrieve and display the solution
